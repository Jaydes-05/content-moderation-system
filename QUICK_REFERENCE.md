| Tab | Icon | Purpose | Key Features |

## 🎯 Quick Actions

### Analyze Comments
1. Click ContentGuard button (bottom right)
2. Click refresh button (🔄)
3. Wait for analysis to complete

### Export Report
1. Click export button (📊)
2. Choose format:
   - CSV (spreadsheet)
   - JSON (data)
   - PDF (report)

### Batch Moderate
1. Go to Batch tab (📦)
2. Click "Select All Toxic"
3. Choose operation:
   - Hide Selected
   - Block Users
   - Approve Selected

### Check Community Health
1. Go to Health tab (💚)
2. View health score
3. Check metrics and trend

## 🧠 AI Features

### Sarcasm Detection
- **Detects**: lol, jk, /s, 😂, "quotes", ...
- **Badge**: 😏 Sarcasm
- **Effect**: Reduces toxicity score by 60%
- **Toggle**: Settings → AI Context Analysis

### Context Analysis
- Understands jokes vs genuine toxicity
- Reduces false positives by 40%
- Automatic - no configuration needed

## 📦 Batch Operations

### Selection
- **Select All Toxic**: Selects only toxic comments
- **Select All**: Selects every comment
- **Deselect All**: Clears selection
- **Manual**: Click checkboxes individually

### Operations
- **Hide Selected**: Blur and fade comments
- **Block Users**: Block comment authors
- **Approve Selected**: Mark as safe
- **Export Selected**: Export only selected

## ⚙️ Settings Quick Reference

### Auto-Moderation
- ☑️ Auto-hide toxic comments
- ☑️ Notify high toxicity
- ☑️ Show heatmap
- ☑️ Show reply suggestions
- ☑️ Track history
- ☑️ **AI Context Analysis** (NEW!)

### Custom Keywords
- Add words to flag
- Comma-separated
- Case-insensitive

### Whitelist Users
- Never flag these users
- Useful for moderators, admins

### Toxicity Threshold
- **Lower** (0-30%): More strict, flags more
- **Medium** (30-70%): Balanced
- **Higher** (70-100%): More lenient, flags less
- **Default**: 50%

## 🐛 Troubleshooting

### Comments not detected?
- Scroll down to load more comments
- Click refresh button
- Check if platform is supported

### Sarcasm not working?
- Check Settings → AI Context Analysis is enabled
- Look for sarcasm markers (lol, jk, /s)

### Export not working?
- Ensure comments are analyzed first
- Check browser download settings
- Try different format

### Health gauge not showing?
- Analyze comments first
- Refresh the page
- Check browser console for errors

## 📊 Metrics Explained

### Toxicity Rate
- % of comments flagged as toxic
- Lower is better
- Target: <10%

### User Engagement
- Based on comment length and variety
- Higher is better
- Target: >60%

### Sentiment Balance
- % of positive vs negative comments
- Higher is better
- Target: >50%

### Moderation Effectiveness
- % of comments allowed (not flagged)
- Higher is better
- Target: >70%
